# БРТС САО — публичная демо-версия

Интерактивный статический прототип CRM-системы учёта брошенных транспортных средств САО.

## Для тестировщиков

- Это демонстрационный стенд: не вводите реальные персональные данные, адреса, ГРЗ или документы.
- Данные живут только в браузере конкретного тестировщика и не синхронизируются между людьми.
- Для входа используйте `admin`; пароль — любой; код 2FA — `123456`.
- Реальное разграничение прав, серверное шифрование, отправка писем, резервное копирование и загрузка файлов появятся только в серверной версии.

## Что проверить

1. Реестр, фильтры, поиск и карточку объекта.
2. Создание объекта, в том числе с кириллическим ГРЗ, например `А001АА77`.
3. Контрольные сроки, отчёты, роли и справочники.

Публикация автоматизирована GitHub Actions через GitHub Pages.

## Для разработчиков

- Тесты: `node --test tests/*.test.mjs` (Node 24, без `package.json`).
- `styles.css` — сгенерированный файл. После изменения классов в `index.html` пересоберите его:

  ```bash
  npx tailwindcss@3.4.17 -c tailwind.config.cjs -i tailwind-input.css -o styles.css --minify
  ```

  Команда воспроизводит текущий `styles.css` байт в байт; новые классы без пересборки не появятся.
